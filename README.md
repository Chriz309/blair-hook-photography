# Blair Hook Photography website

Static site (HTML/CSS/JS, no build step). Hosted on Vercel; every push to `main` redeploys.

- Prices: `js/main.js` (PRICES at the top) and the text on `pricing.html`
- WhatsApp number: `js/main.js` (WHATSAPP)
- Photos: `img/` — large versions are `name.jpg`, grid versions are `name-sm.jpg`
